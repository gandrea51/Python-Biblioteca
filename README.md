# Example of a simple web application with Flask

#### Description
- This repository contains a very simple and basic Python application for managing a small library.
- It is a simple application that manages books and courses and their bookings.
- There is a very simple login system.
- The tools/technologies used are:
  - Python and Flask for the application logic (back-end).
  - MySQL for data management.
  - HTML/ CSS/ JS/ Bootstrap/ Font Awesome for front-end management.
